# Demo 文件怎么用

已拆成两个文件（推荐只按下面用）：

| 文件 | 用途 | 是否入镜 |
|------|------|----------|
| [`DEMO_CUE.md`](./DEMO_CUE.md) | 你跟着操作、照着念 | **否** |
| [`demo-show.html`](./demo-show.html) | 镜头里展示的产品页 | **是** |

旧的 [`demo-record.html`](./demo-record.html) 把「操作说明 + 展示」混在一起，容易露出 STEP 标识，**录视频请改用 `demo-show.html`**。

完整操作步骤见 `DEMO_CUE.md`。
